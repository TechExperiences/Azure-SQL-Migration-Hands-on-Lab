# Lab Overview

This lab demonstrates how **Azure Database Migration Service (DMS)** enables organizations to modernize legacy database environments and establish a cloud-based foundation for analytics, reporting, and AI-driven innovation.

Using the **Zava Retail** scenario, participants experience how an organization evolves from isolated on-premises data systems into a modern, cloud-enabled data platform.

Zava has relied on an on-premises SQL Server environment for more than a decade to manage retail sales transactions. While newer business systems and analytics platforms have moved to the cloud, critical transaction data remains locked in legacy infrastructure, creating challenges for reporting, scalability, and innovation.

To address these challenges, Zava adopts **Azure SQL Database** and **Azure Database Migration Service** to modernize its data estate and establish a unified foundation for future business intelligence initiatives.

# Why Azure Database Migration Service?

Many organizations continue to rely on on-premises SQL Server databases to support critical business operations. While these systems contain valuable business data, they often limit scalability, increase maintenance overhead, and make it difficult to integrate with modern cloud services.

This is where **Azure Database Migration Service (DMS)** becomes essential.

Azure Database Migration Service enables organizations to:

- Migrate databases from on-premises environments to Azure
- Reduce migration complexity and risk
- Establish secure connectivity between environments
- Transfer database schema and data efficiently
- Accelerate cloud modernization initiatives

Azure Database Migration Service bridges the gap between legacy infrastructure and modern cloud platforms, helping organizations modernize existing workloads without rebuilding them from scratch.

# Why Azure Database Migration Service?

Many organizations continue to operate on-premises SQL Server infrastructure that was built to serve legacy business requirements. These environments increasingly constrain scalability, inflate total cost of ownership, and introduce friction when integrating with modern cloud ecosystems.

The strategic response is **Azure Database Migration Service (DMS)**, Microsoft's fully managed migration platform that moves on-premises databases to Azure with minimal operational disruption. For organizations prioritizing cloud transformation, DMS is the layer of execution that translates migration strategy into tangible outcomes.

While SQL Server stores the business data and Azure SQL Database provides the cloud destination, Azure Database Migration Service serves as the migration engine that connects the two environments.

Azure Database Migration Service enables organizations to:

- Establish secure connectivity between source and target environments
- Assess migration readiness and compatibility
- Migrate database schema and data
- Reduce migration complexity and risk
- Accelerate cloud modernization initiatives

Azure Database Migration Service bridges the gap between legacy systems and modern cloud platforms, enabling organizations to modernize existing workloads without rebuilding them from scratch.
